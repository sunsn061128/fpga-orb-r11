## 当前效果和后续比较口径

去除PS每帧输入复制使初始4PPC从82.52提升至106.04FPS；patch加载和行流水继续提升至120.44FPS；通过8ns重建及结构调整得到r17的143.27FPS；u1提前并发DDR请求后达到158.29FPS。相对首次2018.3 4PPC累计提升91.82%。u1中描述子累计周期折算由r17的4.56896ms降至2.237816ms，全部描述子阶段已短于对应下一层图像；当前重叠关键路径主要由图像处理决定。重叠模型6.173464ms与墙钟6.31751ms之差0.144046ms包含末尾写回/响应等，不能当作CPU单独耗时。

后续固定u1作为比较基线。保持相同输入、八层预算、PS循环计时和实际时钟记录，新的时序/数值/AXI/物理板测门槛通过后再发布收益。当前数据没有覆盖外部相机输入、真实变化视频长期负载或P99。

## 发布完整性与复现边界

r15/r16/r17/u1为本地完整封存目录的逐字节副本，保留原MANIFEST和verify.ps1。2024.2归档也保留原目录结构与清单。历史报告中的绝对Windows路径是证据来源；新主机需要安装对应工具链、配置路径并恢复外部依赖。此次上传只进行文件、Git和清单校验，没有重新综合、路由或上板，未声称迁移目录后的完整重建通过。
